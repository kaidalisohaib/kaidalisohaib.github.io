## Icon Generation
These icons can be generated from a single high-resolution source image (preferably 1024x1024 PNG) using tools like:
- [Favicon.io](https://favicon.io/)
- [RealFaviconGenerator](https://realfavicongenerator.net/)
- [PWA Builder](https://www.pwabuilder.com/)

## Design Guidelines
- Use the brand color #4f46e5 (indigo-600)
- Ensure good contrast and readability at small sizes
- Consider using initials "SK" or a simple geometric design
- Maintain consistency across all icon sizes
