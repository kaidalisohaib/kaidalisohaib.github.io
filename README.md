- Responsive design for all devices
- Modern UI with smooth animations
- Interactive project filtering
- Contact form with validation
- SEO optimized

Visit: [https://kaidalisohaib.github.io](https://kaidalisohaib.github.io)

## 🛠️ Technologies

- HTML5, CSS3, JavaScript
- Font Awesome icons
- Google Fonts
- GitHub Pages deployment

## 🔧 Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/kaidalisohaib/kaidalisohaib.github.io.git
   cd kaidalisohaib.github.io
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run serve
   ```

4. **Open in browser**
   Navigate to `http://localhost:3000`
