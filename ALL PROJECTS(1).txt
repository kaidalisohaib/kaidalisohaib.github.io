* Problem Solved: University course catalogues are often presented as dense text, making it difficult for students to understand the complex web of prerequisites, corequisites, and program requirements. * Primary Technologies:

2. Key Features & Functionality
* Main Modules:


   1. mcgill_scraper (Data Acquisition): A Scrapy project containing two spiders. One spider scrapes detailed information from individual course pages, while the other crawls program listings to map programs to their required courses.
   2. processing_scripts (Data Enrichment): A sophisticated Python pipeline that takes the raw, unstructured prerequisite text scraped from the web, uses a Large Language Model (LLM) to parse it into a structured JSON format, and prepares it for the frontend.
   3. Frontend Interface (Root Directory): A single-page application that loads the processed data and renders it as an interactive graph. It includes controls for filtering by program, searching for courses, and highlighting courses by subject category.

   * LLM-Powered Prerequisite Parsing: The most innovative feature is the use of the Google Gemini API to translate ambiguous, natural-language requirements (e.g., "LING 330 and LING 320 or permission of instructor.") into a deterministic, logical JSON structure (e.g., {"operator": "OR", "conditions": [{"operator": "AND", ...}, {"type": "TEXTUAL", ...}]}).    * Resilient Asynchronous API Client: The parallel_gemini_requester.py script is a standout piece of engineering. It uses asyncio and aiohttp to make concurrent API calls, respecting rate limits with a semaphore, and implementing exponential backoff for retries. This ensures the data processing is both fast and robust against network or API issues.

   2. Transform: The process_prerequisite.py script reads the raw data, constructs detailed prompts, and sends them in parallel to the Gemini API via the async requester. The LLM's structured JSON response is then integrated back into the course data.
   3. Load & Visualize: The user opens index.html. The main.js script fetches the final processed JSON files.
