# Image Assets Required for SEO

This directory should contain the following image files for complete SEO and social media optimization:

## Social Media Images
- `og-image.jpg` (1200x630) - Open Graph image for Facebook, LinkedIn, etc.
- `twitter-card.jpg` (1200x630) - Twitter Card image
- `profile-photo.jpg` - Professional headshot for structured data

## PWA Screenshots
- `screenshot-desktop.png` (1280x720) - Desktop view of the portfolio
- `screenshot-mobile.png` (390x844) - Mobile view of the portfolio

## Project Images
- Project thumbnails and screenshots for the portfolio projects
- Optimized in WebP format with JPG/PNG fallbacks

## Image Optimization Guidelines
- Use WebP format for modern browsers with fallbacks
- Compress images for web (aim for <100KB for social images)
- Include proper alt text in HTML
- Use responsive images with srcset when appropriate
- Maintain aspect ratios: 1200x630 for social media cards
